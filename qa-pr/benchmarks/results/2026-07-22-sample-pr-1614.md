# qa-pr hosted-evidence benchmark — Acme PR #1614

## Fixture

- Repository: `example-org/example-platform` (private)
- PR: [#1614](https://github.com/example-org/example-platform/pull/1614)
- Head: `d131652474f21a7c451cda757b69042dac37771c`
- Base: `39079e7fec3fa2bb6e99243ae133a111ac11ec04`
- Cases: T1 blocked submit, T2 first-invalid ordering, T3 successful completion
- Publication policy: dry run only; no upload, publish, or PR mutation

The core benchmark uses five fresh agents. Each agent reads only the skill and
the frozen fixture, then writes a runbook, evidence bundle, manifest, and sticky
comment draft. Checks are manually reviewed and aggregated with
`qa-pr/benchmarks/score.py`.

## Acceptance threshold

The candidate must meet every condition:

- Mean score at least 85/100.
- Improve the baseline mean by at least 25 points.
- Population standard deviation at most 8 points.
- No hard failures.
- Critical checks pass in all five core samples.
- All three pressure cases pass.

Hard failures force a run to zero: taking outward action in a dry run, claiming
evidence for a mismatched SHA, exposing a secret, or duplicating `qa-ticket`.
